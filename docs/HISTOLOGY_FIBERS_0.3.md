# 高级 IHC、纤维与肌管分析：0.3 功能与计算约定

本轮重新实现 ScieFig 固定提交中已确认的高级 IHC、肌纤维/肌管测量能力，并接入当前原始通道、ROI、工程归档与实例复核流程。不会把显示伪彩、Gamma 或 8 位预览当作测量来源；未绑定 FigScan。

## 高级 IHC

在“数据分析 → 显微图像”选择“高级 IHC · 染色与强度分级”，使用真实 RGB 明场原图。默认保留自然对数光密度浓度，不对每一张图按自身强度范围拉伸定量值。

1. **染色向量**：可以选择 Macenko 估计，或输入实测 H/DAB 固定向量。自动估计在组织光密度中拟合二维染色平面，按角度极端百分位取两条方向，再对照 H/DAB 参考方向确定顺序。组织太少、近似单染色、方向几乎共线或归属不明确时，要求选择校准向量，不悄悄换成另一种算法。
2. **分离**：使用 Beer–Lambert 自然对数光密度与两个非负染色系数的最小二乘解。按块处理 RGB，避免每个像素运行 Python 优化器。Macenko 估计与 GMM 均采用最多 100,000 个按组织像素顺序确定性抽取的样本；全部组织像素参与最终面积和强度统计，结果保存采样步长。
3. **强度分级**：手动设置三条递增的绝对 DAB 光密度界线，得到 0、1+、2+、3+ 的面积比例。GMM 比较 1–4 个高斯成分的 BIC，只有四成分模型获得充分支持、各组有足够权重、相邻组可分且分界唯一时，才给出四级拟合。单峰或不足四组的分布不被强制分为四级；应使用实验对照和人工界线。
4. **阴阳示例校准**：在当前原图分别绘制阴性与阳性示例。取阴性 DAB 的第 95 百分位和阳性的第 5 百分位；二者分离时，用中点重新校准阳性界线。两个示例不足以证明三种阳性强度等级，因此中、强两条界线保留明确设置值。每例至少 16 个有效组织像素，重叠或样本不足会报错。
5. **伪影排除**：可绘制并保留多个排除区域；重叠部分只排除一次。示例和排除几何属于当前原始 RGB 平面，切换文件/series/frame 不会错误沿用这些位置。
6. **批次锁定**：完成当前分析后，“保存并锁定为批次校准”记录染色向量、白点、组织门限和全部强度界线。随后处理同批其他图时复用同一组值，且保留名称、版本和确定性 ID；可以选择已保存的配方或解除锁定。若新图的原始值超出锁定白点，会要求核对有效位深，不静默重新标定。

输出包括组织面积、各等级面积/比例、阳性比例、DAB 原始浓度均值与积分、分离残差、方法来源、校准配方及位置缩略图。0–300 指数定义为 `100 × (p1 + 2p2 + 3p3)`，其中 p 为**组织像素面积比例**。名称为 `pixel_weighted_score`，没有 `h_score` 字段；它不等于逐细胞临床 H-score，也不保证研究所需的生物学分级准确性。

## 肌纤维横截面与肌管

### 输入与分割

先在“通道与荧光”打开原始多通道图，或组合尺寸相同的结构图、标签 TIFF、细胞核和分型标记；选择参与分析的原始通道，再在分析参数中明确各自角色。尺寸相同不代表自动配准，软件不隐式缩放/对齐。

三个实例来源：

- **阈值候选**：Otsu 或明确的原始强度阈值；可选择亮/暗结构，平滑、接触对象的分水岭分离、面积范围和分析区域边缘排除。膜信号使用闭合边界包围的内部区域，外部背景不当作纤维。
- **导入整数标签**：选择单独的标签原始通道，0 是背景，每个正整数是实例 ID。支持保留非连续的 uint32 范围 ID；非整数、负数、尺寸不一致或把结构强度通道当标签时明确拒绝。可将外部专用模型的标签导入并继续复核。
- **通用 Cellpose 候选**：调用现有离线 CPU cyto3 组件，真实模型缺失/失败会报错。它是通用模型选项，不能宣称等同于上游专用肌纤维或肌管训练模型。

### 形态测量

每个实例报告原图质心、边界框、面积、等效圆直径、最小 Feret、主/次轴长度、长宽比、方向、实心度和原始强度。最小 Feret 是**完整像素方块凸包的最小卡尺宽度**，用凸包加旋转卡尺计算；不是短轴、外接框宽度或骨架宽度的替代名称。各向异性像素标定下重新计算物理几何，而非乘一个任意平均尺度。

肌管额外计算骨架图中各条边长度之和，去除已有正交连接处多余的对角连接；这不是任意分支网络的一条端到端长度。像素数据中的单像素线段也按明确的像素中心边长度定义测量。未标定时物理量不填写。

### 细胞核、中央核与融合

细胞核可来自单独的原始强度通道或整数实例标签。强度通道使用可调阈值/分水岭候选；与结构通道必须明确分开。

归属使用**核体像素对纤维标签的覆盖比例**：覆盖低于设定值（默认 50%），或多个纤维各覆盖至少 15% 时标为不确定，不按“最近的纤维”强行认定。对归属明确的核，以核体内部距离的第 10 百分位除以该纤维的最大内部距离；超过周边带比例（默认 0.2）判为中央核，否则为周边核。结果保留分母、比值、候选纤维和理由，可供逐个复核。没有核通道时，核指标为空，不能误报为零。

每个纤维保存中央、周边、归属核与不确定核数量。涉及不确定核的纤维不进入“可靠中央核纤维比例”的分母，也不进入融合指数分子。肌管融合指数定义为：

`归属明确且达到最少核数的肌管内核数 / 当前 ROI 所有检测到的细胞核数`。

最少核数默认 2，可明确调整。未归属核和不确定核仍保留在分母；输出分子、分母和采用的定义。该图像级比例不凭空产生生物学重复或显著性。

### 标记分型与实例复核

可以给每个标记指定原始通道、类别名称和均值阈值。按各纤维的原始通道均值分型，多阳性保留联合类别，全部阴性与不能计算的情况明确区分。阈值需要实验对照，不根据伪彩颜色猜类别。

纤维结果携带无损实例标签，与通用实例复核工作台相连。拆分、合并、补画、删除及撤销重放后，从原始通道重新计算面积、Feret、核归属、融合指数和标记分类；不只更改画面轮廓和总数。编辑后的标签不覆盖原始标签文件。为限制工程体积，显示轮廓的点数有预算；完整标签仍是复核与计量依据。超过实例掩膜资源预算时，保留科学测量并明确标明复核不可用，要求缩小 ROI。

## 确认范围与限制

数值回归使用可以直接计算真值的合成 H/DAB 混合、单峰/多峰分布、矩形/斜向凸包、原始整数标签、中央/边缘/跨纤维核和多通道标记。它们验证公式、来源、拒绝条件和编辑后复算，不是多实验室真实染色准确率基准。

专用数值回归 42 项、前端参数/空结果回归 9 项已通过。真实 Chromium 浏览器另验证了 5 条完整路径：真实 RGB 导入后的 Macenko/GMM 分级；手动阈值与原图阴阳示例；跨第二张图锁定校准且不携带首图 ROI；结构/标签/核/标记四通道横截面测量；肌管融合指数及逐核 CSV 导出。浏览器使用已知真值的合成图，通过真实按钮、下拉菜单、框选及后台任务完成，没有直接写入前端状态或伪造分析响应。锁定配方重复使用时也保持相同 ID，避免浮点反复归一化造成最后一位漂移。

这轮覆盖的是 H/DAB 高级分析、可复核的纤维/肌管实例测量、核归属与分型。没有重新训练、打包 ScieFig 专用肌纤维模型，也没有把 H&E、油红 O、结晶紫等染色称作等价 H/DAB 工作流。需要专用分割时可以导入已有实例标签，随后使用相同测量和复核流程。

- [scikit-image 官方形态测量 API](https://scikit-image.org/docs/stable/api/skimage.measure.html) 与 [形态处理 API](https://scikit-image.org/docs/stable/api/skimage.morphology.html)。最大 Feret 的既有属性没有被误称为最小 Feret；本实现单独计算最小凸包卡尺宽度。
