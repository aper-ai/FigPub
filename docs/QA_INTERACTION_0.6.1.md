# 0.6.1 任务生命周期与交互复核

## 复核结论的范围

重新下载并校验了 v0.6.0 的原始验收证据：其 732 项 Python、225 项前端、74 个浏览器场景、15 个原生场景和两个包内模型测试记录与发布包一致。该结果说明已覆盖用例通过，不代表所有用户操作组合均被覆盖。

本轮继续检查慢请求、连续操作、键盘语义、对话框关闭和跨素材任务返回，发现并复现了以下漏测缺陷。修复代码、回归测试与发布流程一同纳入 0.6.1；最终执行数量和发行状态以同一提交的 GitHub Actions 与 RELEASE_ACCEPTANCE.json 为准。

## 复现与修复

| 操作 | v0.6.0 的问题 | 0.6.1 的处理 |
| --- | --- | --- |
| 保存或提交较慢时连续运行分析 | 首次 await 前没有提交锁；可出现两个 POST，界面只跟踪后一个任务 | 在首次异步保存前取得提交锁，展示保存/提交状态；提交及活跃任务阶段阻止重复运行 |
| 已提交任务的状态 GET 失败 | 界面将 job 清空，后台任务仍可能执行 | 有界重试查询；持续失败仍保留已知任务 ID，允许重试查询或取消，不重新提交计算 |
| 结果已完成但项目读取失败 | 无法可靠区分计算失败和结果读取失败 | 保留任务，重新读取同一结果和项目；确认完成、取消或实际失败后再释放运行入口 |
| 图像分析页的按钮获得焦点后按 Space / Enter | 全局平移或多边形快捷键可能截获按钮按键 | 保留原生控件的键盘语义，画布自身继续支持 Space 平移和 Enter 完成多边形 |
| 关闭、Escape 或遮罩退出对话框 | 焦点没有返回原触发控件 | 在同一项目与工作区恢复准确的触发控件；切换上下文、触发控件消失或仍忙碌时不误抢焦点 |
| qPCR 任务 A 运行期间查看表 B，再返回任务 | 可能显示 A 的标题和 B 的表格行 | 返回任务时经正式素材选择与工作表读取路径恢复，重新核对表格身份 |
| 分析、条带识别或 WB 图组生成期间尝试切换项目，随后任务已结束 | 项目切换被正确阻止，但任务结束后仍可能保留旧的运行提示 | 提示关联具体提交、识别或图组生成任务；状态解除后移除对应横幅与通知，保留无关错误 |

取消与完成同时发生时，按服务实际终态处理。已经完成的任务会读取结果，不显示为成功取消。过期异步响应不能覆盖较新的任务或恢复已取消的任务。

## 验证方式

控制器回归使用生产任务控制模块和可控制的异步依赖，覆盖保存延迟、POST 延迟、拒绝提交、状态查询失败、项目结果同步失败、取消失败、取消与完成竞态以及再次分析。DOM 回归调用生产事件和渲染逻辑，验证按钮语义、项目切换护栏和焦点生命周期。

`tests/browser_task_lifecycle.py` 使用生产 HTTP 应用、JobManager 和数值算法。测试中间件只注入延迟或错误状态，不伪造成功的分析结果。取消场景暂时占用实际工作线程，使待测任务确定处于队列中，再经界面取消并确认没有写入结果。所有阻塞条件均在清理阶段释放。

浏览器检查包括：真实双击只产生一个提交；持续查询失败后保留同一任务；跨页和跨数据表返回正确输入；恢复查询后得到真实 qPCR 结果且旧任务阻塞提示已清除；明确拒绝后可重试；排队任务取消后可再次分析；16-bit 图像使用键盘运行后结果正确；对话框返回焦点；画布平移不修改项目数据；真实条带识别在取消与完成两条路径上清除对应阻塞提示。

第一轮 Windows 异常交互预检通过后，逐图复核发现了上述“已完成后旧提示残留”的遗漏；进一步检查了 WB 图组生成与条带识别的同类护栏，补齐各自生命周期，因此未将这些中间候选发布。修复后的候选必须重新执行同一套真实浏览器流程，并按最终源码完成整包验收。截图复核与功能断言分别记录，测试数量不作为不存在其他缺陷的证明。

新增交互预检在 Windows 上先运行。通过后才进入完整工具包构建，并再次执行全部科学流程、最终 ZIP 新目录解压、两个包内模型与原生客户端验收。发布流程仍要求精确源码、原始候选字节、全部报告和远程附件校验一致。

## 当前仍需明确的产品边界

- 全局撤销快照主要记录可编辑配方；素材导入会清空该历史，不能称为全部操作统一可撤销。细胞实例等工作流另有各自的编辑记录。
- 科学回归主要采用可独立计算预期值的合成数据。真实实验图像识别准确率需要另行建立经人工确认的数据集评估。
- 三个窗口尺寸的布局验证与键盘回归，不等于 Windows 各版本、多显示器、多 DPI 或完整无障碍合规验证。
- 已有专业工作台的信息分区、任务状态与数据流转基础；尚未用真实新用户研究证明上手成本，也没有以有限测试声称行业性能领先。

当前开发执行环境的 Chromium 启动被 Unix socket 权限限制阻断；该本地尝试记录为未执行成功。正式界面结论以本轮 Windows 真实浏览器和原生验收为依据，不将环境阻断记作通过。
