# 图研 0.3.0：重构设计与代码边界

## 目标与范围

这是一个从原始素材到最终科研图稿的本地工作台。参考 GelFigure 的凝胶定位与标注流程，以及 ScieFig 的定量、显微与多面板排版需求，重新实现可组合的数据和计算层。

此版本不接入 FigScan，不要求云账号、上传原始实验文件或下载模型权重。核心不是旧 GUI 的拼装，也不运行两套上游应用。新实现仍使用成熟的 NumPy、SciPy、scikit-image、Matplotlib、Pillow、PyMuPDF 等基础库；这些依赖和许可证单独列明。

## 一份工程，三个坐标域

`ProjectDocument` 是带版本的结构化工程；模型在 `workbench/models.py`，完整接口在 `docs/CONTRACT.md`。

| 数据 | 单位 / 约束 | 目的 |
|---|---|---|
| `SourceAsset` | 不可覆盖的原始字节；SHA-256 内容身份 | 不让预览代替原图；相同来源可在多个面板引用 |
| `SourceCrop`、定量 ROI、泳道和 Marker | 原图像素 px | 分析始终能回到相同原始数据 |
| `FigureGeometry`、`Panel`、图版标注位置 | 毫米 mm | 排版尺寸与期刊要求、输出一致 |
| 字号、线宽 | 磅 pt | 导出不会因画布缩放改变字号 |
| `DisplaySettings` | 原始强度黑白点、Gamma、反色 | 只影响显示，不能改变计算输入 |
| 测量记录 | 参数、来源 ID、项目版本和实际结果 | 可核对、可重新计算，不把历史值冒充当前结果 |

对象 ID、来源引用、有限数值、尺寸和归档结构在输入边界验证。分析核心使用 `PixelRegion`、`BlotRegion`、`CtObservation`、`SpatialCalibration` 等明确的数据类型，不传 GUI 控件或屏幕坐标。

## 性能选择

### 原始像素与显示分离

不可变原件不进入前端撤销栈。16 位输入仍为 16 位数组；定量先取 ROI 视图，再对需要计算的像素转为 float64。不会每画一条 ROI 就把整张大图复制成浮点数组。

浏览器只接收适合显示的预览和有界定位像素。定位像素通过 float32 二进制传输，避免把数十万数值转成 JSON 字符串；`ArrayBuffer` 交给 Worker，不阻塞主界面做条带计算。分析不使用这些缩小后的像素。

可映射 TIFF 优先使用只读内存映射。数组、预览、表格与定位均有内存上限；缓存键包含来源哈希、页码、通道、尺寸和显示参数，防止读到另一个显示版本。

### 拖动不重做整张图

拖动过程中使用 `requestAnimationFrame` 更新活动对象的位置/形状；结束后只提交一次编辑和自动保存。撤销历史最多保留 60 个编辑配方快照，不深复制原件、已完成测量、源表和轮廓数据。撤销不能让已保存分析结果或源素材从后台生命周期中消失。

### 后台任务有明确身份

任务记录启动时的工程 ID、revision、来源文件和参数。取消会立即改变任务状态并禁止后续提交；已经进入 NumPy/skimage 的原生 CPU 调用会在返回后释放线程。最多两个工作线程，避免无限创建线程拖慢桌面。

结果提交时再次检查工程身份。若原图、参数或工程已变更，旧结果不会覆盖新编辑。前端串行保存；分析结果追加与本地待保存配方之间的版本竞争只按可确认的同任务结果处理，不盲目重试覆盖未知修改。

界面使用 `analysis-domain.js` 的同一份参数构建和规范化签名来提交分析、选择结果与生成图表。签名覆盖实际来源、ROI 和科学参数，不包含图稿位置或图表外观。优先显示与当前输入完全匹配的已保存测量；同源历史值明确标记过期，其他源图或表格的结果不会串到当前素材。已经计算但未成功保存的结果不能用于创建正式图表。撤销/重做也同步分析参数，新工程从独立默认值开始。

## 一致的图像变换

面板变换顺序为：**原图坐标裁切 → 保留泳道片段并显示间隔 → 翻转 → 绕面板中心旋转**。泳道、Marker 和比例尺随内容旋转；面板编号与标题保持直立。原图坐标始终不变。

有效 PPI 按实际保留的源像素和最终放置尺寸计算。把输出设置为 600 DPI 不会增加原图细节。PDF/SVG 容器也可能含低分辨率栅格，必须检查内部对象，不能只根据扩展名认定为矢量。

SVG 的预览、预检和导出共用严格转换路径，保持裁切与矢量图形。输出明确写入物理尺寸，避免 PDF 点数与 CSS 像素混用造成 75% 缩放。当前不可靠的 `mask`、`filter`、嵌套 SVG 视口、`objectBoundingBox` 裁切及部分混合/分组透明度效果会明确报错，可由源绘图软件转换为受支持的 PDF 或路径。原 SVG 字节不会被覆盖。

## 数值规则

- WB 内参按实验、样本、生物学重复及技术重复匹配；多个曝光不能自动增加独立样本数。
- 背景扣除保留有符号净信号。饱和与不可量化结果显式报告，不能裁正后偷偷进入统计。
- Rolling ball 调用真正的非平坦滚动球算法，不把均值滤波改名为 rolling ball。
- qPCR 技术孔先合并，再计算 ΔCt、ΔΔCt；对照基线来自生物学样本。中间计算不提前舍入。
- `n=1` 的 SD/SEM 是缺失值，而不是伪造的零误差条；不自动画显著性星号。
- IHC 阳性连通区域数不冒称阳性细胞数或细胞 H-score。物理尺度未知时报告 px/px²。
- 自动 Marker 只产生候选，需要确认真实试剂型号和对应条带。插值与外推分别标记。

## 可靠性边界

工程采用原子替换并保留上一份自动保存备份。可移动归档包含全部来源文件和校验清单，打开时验证哈希；校验能证明字节一致性，不能证明实验真实性或仪器来源。

本机服务只监听 loopback；写请求检查同源；SVG 和归档禁止外部活动资源。启动器对工作目录加单写锁，避免两次启动同时修改同一工程。直接用 ASGI 工厂启动服务属于开发方式，调用方应自行避免对同一目录开多实例。

## 验证与后续门槛

每个确定的数值、几何、存储和状态问题都用相应回归验证。测试覆盖和实测数据分别在 `tests/`、`benchmarks/`，验证报告记录实际机器与合成数据。

首版的合成测试不能代替多实验室真实样本验证，也不能证明优于所有同类产品。临床解释、实验真实性识别、深度模型精度和原项目全部高级功能不在这个版本的已验证范围。扩展功能应继续遵循同一份原始数据、单位、来源和任务契约，而不是再建立第二套状态。

## 0.2：多维来源的唯一身份

每个科学平面使用 `(asset_sha256, series, frame, channel)`。`frame` 按非 Y/X/C/S 轴的原顺序作 C-order 展平，描述接口同时给出 T/Z 坐标；同时有 C 与 S 时把 C×S 组件明确展开，保留 logical_channel/sample/role 元数据。所有预览、定位、测量、导出都调用同一解码器，不再各自解释页号。RGB 成分与独立荧光通道的语义分开，IHC 要求真正的 RGB 原件。

`ChannelView` 只保存原件引用与显示配方。不同原件保留各自 dtype，禁止通过 stack/promote 创建伪装成原始值的“新原图”。组合要求相同源像素尺寸；没有隐式配准或插值。分屏布局返回原图坐标与 tile 坐标映射；ROI 不存屏幕像素。分屏导出逐 tile 创建场景图像和矢量 caption/比例尺，预检按各 tile 实际物理尺寸计算 PPI，间隙不计作源细节。

渲染按通道和条带推进 LUT，不保留每个通道的全幅浮点副本；大 RGB 累加缓冲使用临时映射文件。后端预览缓存限制总字节与条目并合并并发同键请求；前端 Blob 缓存有淘汰和 URL 释放，不让滑条累积无限预览。元数据与抽样百分位独立标记，原图统计与显示预览不能混为一谈。

统计只使用已经聚合的独立生物学重复；技术孔和曝光不能增加 n。组间检验隔离实验及靶标/蛋白，配对依赖明确 ID。零方差、重复不足或没有完整配对返回 null 和原因；同一比较族 t 检验使用 Holm，Tukey 返回自身校正的 p 值。

Cellpose 第三方组件独立使用 NumPy 2.0，不与主程序 NumPy 2.x 混装。启动器仍只需双击；模型包随完整版提供。worker 加载前和实际推理前均验证官方权重身份，禁止工程数据指定可执行程序或任意模型文件。取消会终止子进程，任务结果仍遵守版本提交规则。模型生成的是分割标签，像素强度统计重新读取原始平面。


## 0.3：原始像素、派生结果与人工修订

新增 `histology.py`、`fibers.py`、`instances.py`、`wb_workflow.py` 各自承担独立纯计算；现有任务队列继续负责运行、取消和工程版本提交。`workflow_api.py` 只读取已保存工程与原始来源，复核和质量推荐 API 采用项目 ID/版本及基准掩膜校验，不自行覆盖工程。

WB 用原图 `asset_id/series/frame/channel` 绑定所有候选与 ROI。向导草稿是可编辑配方，定量 ROI 是正式分析输入，图稿保存连续原图裁切和已保存的真实分析来源。跨图控制 ROI 通过明确 ID 和实验身份关联；分析草稿范围包含其真正引用的内参。

IHC 配方锁定染色向量、白点、组织与强度门限。示例和排除位置属于原始平面几何，跨图切换不复制坐标。染色估计与 GMM 采样有界，最后面积与强度统计仍覆盖全部所选组织像素。

分割原始标签以有界无损 uint32 压缩保存。编辑历史只记录操作与游标，项目撤销不复制整幅标签；衍生结果在原始标签上重放后重新计算。修订标签不覆盖自动分析和原图。掩膜 SHA-256 同时绑定字节、ROI 原点、形状与原图尺寸。

实例复核与曝光推荐共用两并发计算槽，忙时返回可重试状态；输入大小、平面数、ROI 数和掩膜展开大小均有限制。已有预览缓存和二进制 Worker 仍负责图像显示与条带定位，显示 LUT 不进入定量输入。
