# 0.6 数据输入、保存恢复与导出核验

## 核验范围与状态

本轮以后端实际复现为依据，检查原件导入、qPCR 读取与定量、工程替换、分析结果提交、工程归档与重开、成图导出的数据完整性。新增回归位于 `tests/test_workflow_regressions_06.py`，覆盖 28 个参数化场景。

本报告记录本地 Python 测试已经执行的结果。浏览器交互、完整 Cellpose 安装包、Windows 原生客户端与发布包验收由独立流程执行；本报告不把这些尚未执行的验收计为通过，也不代表对任意真实科研图像的准确率保证。

## 已复现并修复的问题

| 问题 | 原有结果 | 修复后的行为与证据 |
| --- | --- | --- |
| 新建、打开工程时磁盘保存失败 | 内存中的当前工程已被替换，磁盘仍保留旧工程；界面和重启后的状态不一致 | 先验证待提交快照，持久化失败则恢复原工程。注入一次 `current.json` 写入失败后，验证当前工程、磁盘文件和重启状态均保持一致；重试成功 |
| 原件注册表写盘失败后重试 | 内存已登记原件，重试跳过注册表写入，随后工程可能引用一个重启后找不到的原件 | 注册表先落盘，再更新内存引用。注入 `assets.json` 写入失败后重试，验证原件 SHA-256、字节内容、当前工程和重启恢复一致 |
| 分析结果提交超过工程容量 | 分析任务显示完成，但保存的工程超过同一应用的读取限制，下次启动无法正常恢复 | 在追加分析结果、修订号和审计记录后重新验证最终快照；超限任务报告错误，既有工程和持久化文件保留 |
| CSV/TSV 超出表头的非空字段 | 额外字段被静默舍弃 | 拒绝导入并提供行号与字段引号检查提示；当前工程保持不变。合法的带引号分隔符和额外空字段仍可导入、归档和重开 |
| CSV 未闭合引号 | 解析器可能把后续数据行合并成一个字段并接受导入 | 通用表格和 qPCR 读取均使用严格引号解析；损坏文件在进入工程前得到明确错误 |
| Excel 数字 `0` 表头 | 被当成空值替换为 `column_1`，改变列身份 | 保留为字符串列名 `0`；只有空白表头采用占位列名 |
| Excel/JSON 布尔 Ct | `True`/`False` 转换成 Ct 1/0，影响技术均值、ΔCt 与表达倍数 | 布尔值按无效 Ct 处理，保留原始行号和 `undetermined_or_invalid_ct` 排除原因；其余有效记录正常分析 |
| qPCR 工作簿先完整加载所有工作表 | 大型、无关元数据表会占用内存，甚至阻断另一张合法 Results 表 | 各工作表仅扫描前 100 行候选表头，按原有评分规则选择后，只完整读取选中的表；含第 200001 行元数据的稀疏工作簿可正常读取另一张 Results 表 |
| qPCR 读取缺乏统一资源边界 | 文本表没有行/列/单元格上限，XLSX 行数检查在完整加载后才执行 | 在逐行读取时检查行数、列数和累计单元格数，在保留整表前拒绝超限输入 |
| 合法大画布无法导出 | 项目模型允许 2000 mm，但导出场景只接受 1000 mm | 场景上限与现有模型统一为 2000 mm；保存、归档、重开后 PDF/SVG 的实测物理尺寸保持一致 |
| 小尺寸 PPTX 静默扩大画布 | 小于 25.4 mm 的边被自动扩大到 25.4 mm | PPTX 独立检查格式支持范围，超限提供明确提示与 PDF/SVG 选项，不修改工程尺寸；合法边界尺寸回读验证一致 |

本地 I/O 故障现在以结构化 HTTP 503 / `local_io_error` 返回，并提供磁盘空间与存储设备状态检查提示。原有“文件不存在”和“权限不足”专用响应继续保留。

## 定量结果与数据身份

qPCR 回归采用可手算的独立预期值：对照组内参 Ct 为 20、目标 Ct 为 22，处理组内参 Ct 为 20、目标 Ct 为 21，因此对照 ΔCt 为 2、处理 ΔCt 为 1，处理组表达倍数为 `2^−(1−2) = 2`。增加一个布尔 Ct 单元格后，预期结果仍为对照 1、处理 2，并验证该孔仅以无效记录保留。

未更改 ΔΔCt 计算、技术重复聚合、生物重复统计、IHC/纤维/实例编辑算法或图像像素处理。保留 source_row、原件内容哈希、排除原因和归档中的原始字节。更新了 qPCR 分组、Ct 复核和显微标定的用户提示，使其使用明确的专业描述。

## 保留的边界

- 工程 JSON 上限保持 16 MiB。超过容量的结果不能覆盖最后一个可恢复工程。
- 独立 qPCR 读取器至多读取 200000 行（含表头及前导元数据）、512 列、2000000 个单元格；通用原件导入继续保留其原有更严格的表格限制。表头发现仍限定于前 100 行。
- 图版物理尺寸为每边 1–2000 mm。PDF/SVG 支持该范围；PNG/TIFF 仍拒绝超过 1 亿像素的输出，回归确认在实际栅格化前拒绝。
- PPTX 每边须为 25.4–1422.4 mm。该范围来自当前锁定 `python-pptx` 的幻灯片尺寸校验，回归验证上下边界的真实 PPTX 文件。超出范围时建议调整版面或导出 PDF/SVG，不自动缩放或扩展。
- `Ct > 35` 仍是复核标记；仅用户设置的排除条件才改变这些有效 Ct 的纳入状态。布尔 Ct 属于无效数值输入，与该阈值规则分开处理。
