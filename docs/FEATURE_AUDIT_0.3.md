# 0.3 功能补全与修复核对

本轮落实两组需求：高级 IHC／纤维／实例人工修订／多曝光质量推荐，以及 WB 自动定位到可编辑 ROI 与完整图稿。下面的“完成”指已实现、接入用户界面并通过明确的数值与操作验证；没有将专用模型训练、真实实验精度或 Windows 真机验收混入完成范围。

## 功能矩阵

| 本轮要求 | 0.3 实现 | 用户操作与证据 |
|---|---|---|
| 自动条带直接成为定量 ROI | 候选按原始位置分行，生成可编辑矩形；保留文件/series/frame/channel；纳入、身份、坐标可继续修改 | 导入 WB 入口；`wb-domain.js`、`wb-workflow.js`；7 条 WB 浏览器场景 |
| 目标＋内参＋统计图完整布局 | 同图及跨文件精确配对；原图连续横条；实际保存的分析结果生成统计图；按有效 PPI 控制条带宽度 | 真实定量 n 与图表来源校验；无有效组时不产生虚构统计图 |
| 多曝光质量推荐 | 原始削顶、背景/MAD、信噪、净信号、ROI 几何、完整样本系列；解释性排序和显式应用 | 按实验/系列比较；应用更新逐 ROI 纳入和控制关系，可撤销；不扩大生物学 n |
| 高级 IHC Macenko | 原始 RGB、二维 OD 平面与角度分位估计、H/DAB 排序、非负分离、退化输入拒绝 | 固定向量替代选项；合成染色真值和实际 RGB 浏览器流程 |
| IHC 强度分级与校准 | 手动阈值、受支持的四成分 GMM、阴阳示例、伪影排除、批次锁定 | GMM 不强迫单峰分四级；跨图锁定向量、白点和阈值；坐标按原图隔离 |
| 纤维横截面／肌管 | 结构阈值、膜内区域、导入实例标签、通用 Cellpose；面积、最小 Feret、轴长、骨架、核归属、中央核、融合和分型 | 独立原始结构/核/标记通道，真实像素标定；无核输入不报假零 |
| 细胞实例拆分合并 | 两种子拆分、多选合并、删除、矩形/多边形补画、撤销/重做 | 无损标签选取；前景守恒；CSV/uint32 TIFF；保存工程后重放 |
| 编辑后重新定量 | 重新计算原始强度、面积与质心；纤维同步重算 Feret、核归属、融合、标记分类 | 原图/自动分割结果不可变，人工修订另存操作记录；真实 API 和 UI 导出往返 |

## 顺带修复的实际问题

| 问题 | 修复及影响 |
|---|---|
| 连续导入第二张 WB 会继承旧来源指针 | 导入完成同时清原始平面指针和未完成选择，新向导绑定新图 |
| 分析结果为空时高级结果渲染异常 | 空结果守卫；第一次进入显微页即可操作 |
| 锁定 IHC 配方反复归一化导致 ID 漂移 | 已规范化向量逐位稳定，配方跨图 ID 保持一致 |
| 单峰数据被强行拟合为四级 | 1–4 成分 BIC 与可分性检查；不支持的分布明确要求校准 |
| 原经典显微区域强度包含椭圆/多边形外部像素 | 汇总只使用实际几何内的有效原始像素 |
| 人工分水岭种子产生过小平台碎片 | 等高面、对象内两种子测地分割；并集守恒且两点共同决定拆分 |
| ADC 默认黑点覆盖显式仪器黑电平 | 显式黑电平优先；小数/布尔/非有限 ADC 位数拒绝 |
| 单草稿分析过滤掉跨原图内参 | 分析范围包含显式引用的 control ROI，保留实际来源 |
| 重新开 WB 向导覆盖分析页手改 ROI | 从当前真实 ROI 合并坐标改动，并保留后加手工 ROI |
| 通用结果区容易误把自动分析当成人工修订 | 原始结果与原始 CSV 明确标记；修订结果在复核工作台独立导出 |
| 复核原始多通道累计内存缺乏限制 | 1–32 通道，累计原始平面 512 MiB；细胞/核方法要求唯一强度通道 |
| 含点的 Windows 版本目录导致 ZIP 名被截断 | 构建路径按完整目录名追加 `.zip`，保留完整版本与平台名称 |

## 验证结论

最终通过 **329 项 Python、82 项 JavaScript、39 条实际浏览器场景**，浏览器页面异常为 0，Oxlint 通过。真实官方 nuclei 与 cyto3 均完成 Linux CPU 推理复测。上述数字来自本轮最终运行，没有把 0.1/0.2 的历史数字相加。

六组后端基准均有一次预热和五次实测、确定性结果与原图不变校验。1024² Macenko＋分级中位 68.151 ms；1024² 纤维标签/208 核计量中位 493.760 ms。耗时不含文件解码、HTTP 或 GUI，不据此宣称比上游或行业更快。完整证据见 [VALIDATION.md](VALIDATION.md) 与 [PERFORMANCE.md](PERFORMANCE.md)。

## 明确保留的边界

- 自动定位不识别蛋白身份、实验组别或真实生物学重复；这些必须来自实验记录并确认。
- 多曝光推荐是质量筛选，不替代仪器线性响应校准，不自动用曝光时间缩放强度。
- IHC 0–300 是组织面积加权指数，不是逐细胞临床 H-score；本轮 H/DAB 工作流不等同所有 H&E、油红 O 等染色专题。
- 纤维测量与人工修订流程已完成，但没有重新训练或打包上游专用纤维/肌管模型。可导入专用模型标签或使用通用 cyto3；通用模型不冒充专用模型。
- 复核使用精确标签，单 ROI 最多 1600 万像素、压缩掩膜 2 MiB、100000 实例、200 操作；超限保留分析并提示缩小 ROI，不把近似轮廓当精确标签。
- 主 EXE 包已完成 Windows 静态构建核对；Windows 真机启动、字体、DLL 实际加载及 Office 验收尚未执行。
- 本轮不接入 FigScan，未新增完整 FCS 流式门控、GPU 或所有专有图像格式。
