# 图研 0.3：WB 自动出图与高级图像分析

## 启动与升级

完整解压 `Figure_Workbench_0.3.0_Windows_Main.zip`，双击 `FigureWorkbench.exe`。保留同级的 `runtime/` 和 `app/`，不需要安装 Python 或运行命令。程序会在浏览器打开本机工作台；控制台窗口保持打开，退出时按 Ctrl+C。

使用 Cellpose 时，保留或解压已有 0.2.0 CPU 组件，让 `cellpose/` 与 EXE 同级。0.3 主包与该组件兼容。IHC、经典纤维分割、导入标签、人工复核、WB 定量出图均不要求 Cellpose。

升级前可用“保存工程”备份 `.figwork`。旧工作区和新软件目录分开；打开旧工程后，已有分析记录仍保留。旧分割没有无损实例标签时，需要重新运行一次分割才能人工拆分/合并。

## 上传 WB 后自动生成图稿

1. 点击左下角 **导入 WB 并生成初稿**，选择原始 TIFF/PNG 等图像。系统定位泳道和候选条带，打开出图向导。
2. 核对候选行，明确哪些是目标蛋白、哪些是内参，填写实际蛋白名称。算法只识别位置，不从像素猜蛋白身份。
3. 填写实验 ID、样本、组别、生物学重复，必要时填写技术重复。可以从表格按 Tab 分列粘贴；不要把技术孔或多曝光填写成新的生物学重复。
4. 检查 ROI，必要时改 X/Y/宽/高；没有检测到信号的位置显示为待复核窗口。纳入与否由实际实验情况决定。
5. 点击 **生成 ROI 与整套图稿**。软件建立可继续编辑的 ROI，按原始值定量，并生成目标条带、内参条带和实际统计图。没有有效分组时会说明原因，不造出示例数据。
6. 在“组图排版”调整名称、布局和尺寸，导出 PDF/SVG/PNG/TIFF/PPTX，并保存 `.figwork`。

目标与内参来自不同文件时：先在内参图准备“仅内参”草稿，取消运行定量；再到目标图选择“使用另一原图已准备的内参”，按真实实验、样本与重复身份配对。

多曝光时进入“数据分析 → WB → 比较多曝光质量”。明确曝光系列与 ID，核对饱和/背景/信噪原因，再应用推荐。应用后重新定量。原图保留，选择可撤销。

## 高级 IHC

在“数据分析 → 显微图像”选择“高级 IHC”。使用真实 RGB 原图；选择 Macenko 或实测染色向量，设置人工阈值、GMM 或阴阳例校准。可在原图绘制伪影排除区。

运行后核对染色分离、0/1+/2+/3+ 面积比例和预览。需要同批比较时，点击“保存并锁定为批次校准”，再切换下一张图；锁定的是向量、白点与阈值，示例/排除坐标按每张原图分别保存。

GMM 在数据不足以支持四级时会要求改用明确校准。0–300 指数按组织像素面积加权，不是逐细胞 H-score。

## 纤维与肌管

选择“肌纤维横截面”或“肌管”，勾选原始通道并分别指定结构、核和分型标记。可采用经典阈值、导入整数实例标签，或已有 Cellpose CPU 通用模型。导入标签时，0 是背景，不同正整数代表不同实例；标签通道与结构强度通道分开。

核对面积、最小 Feret、核归属、中央/周边/不确定核、融合指数的分子分母和标记类别。需要 μm/μm² 时填写真实标定；没有核通道时核指标为空。

## 人工修正实例

在已保存且没有过期的分割结果下面打开“实例人工复核”。同一实例内点两个种子拆分；多选实例合并；可删除、矩形补画或多边形补画。补画不能覆盖已有对象，合并不自动填充对象之间的空白。

每次修改都会重算原始强度及相关形态指标；纤维结果同时重算核归属、融合与分型。可撤销、重做和回到自动分割。

**上方保留自动分析的原始结果，下方复核工作台提供修订后的 CSV 和标签 TIFF。** `.figwork` 保存原始标签及操作记录，重新打开可继续编辑。

## 验证范围

本版通过 Linux 数值、原始模型与真实浏览器回归；Windows 包完成静态文件/依赖核对，尚未进行 Windows 真机启动和 Office 验收。测试图像为明确的合成数据，不能当作真实实验准确率保证。详见 [功能核对](FEATURE_AUDIT_0.3.md) 和 [验证记录](VALIDATION.md)。
