# WB 自动出图与多曝光复核（0.3）

这次补齐了原先分散的“定位候选 → 原始坐标 ROI → 真实身份配对 → 定量 → 目标、内参及统计图版式”。普通图片导入保持原有行为；新增 **导入 WB 并生成初稿** 入口才会在导入后自动启动泳道／条带定位。定位不是蛋白身份识别，用户仍需确认实际蛋白和样本信息。

## 同一原图中的目标与内参

1. 点击“导入 WB 并生成初稿”，或在当前图上打开“WB 自动出图向导”。定位在 Worker 中运行，原始数值不被改写。
2. 向导按原始 Y 位置整理候选条带行。为至少一行选择“目标蛋白”，为一行选择“内参”，填写真实蛋白名称。没有把最上／最下行自动当成某种蛋白。
3. 填写真实实验 ID 和各保留泳道的样本、组别、生物学重复及技术重复身份。可从表格按 Tab 分列粘贴。仅靠间距推断的泳道默认不纳入；用户可确认后选择。
4. 初稿自动建立矩形 ROI。默认同一条带行使用一致宽高；可在预览下展开坐标表逐个修改 X、Y、宽、高。目标和内参不能重叠，区域必须完整位于原始平面内。
5. 核对后点击“生成 ROI 与整套图稿”。软件计算原始像素、配对内参，在实际组统计成立时生成真实结果图，并将目标、内参横条与图表排版。所有 ROI、裁切、名称和面板仍可编辑。

某泳道未检出对应信号时，向导显示带虚线的 **参考位置窗口**，不把它称为检出的条带。只有经过用户核对后才纳入测量。这样可以保留“确实无条带”的实际测量，而不是自动删除阴性样本。

## 目标与内参来自不同文件

先在内参图中只选择内参行，取消“运行原始值定量并加入真实统计图”，保存 ROI 与连续横条。随后在目标图的向导中，选择“使用另一原图已准备的内参”，明确选择内参草稿。

跨文件配对逐一核对 experiment_id、sample_id、group、biological_replicate、technical_replicate；缺少或多个匹配时停止，不按泳道顺序猜测。保存的目标 ROI 引用真实 control_roi_id，已有内参不复制成另一个实验样本。自动分析范围包括该草稿的目标及其引用的控制区域。

每个面板保留自身 asset/series/frame/channel、原始裁切与源 ROI 关系。目标和内参各自从真实来源裁出连续横条，没有将不同来源像素拼成一条膜。

## 重开、修改与图稿关系

草稿保存于工程的 `settings.wb_drafts`，实际 ROI 保存于既有 `analysis_rois`。重新打开同一来源、裁切及定位初稿时，当前项目的 ROI 几何会合并到草稿，避免覆盖用户在分析页调整过的 X/Y/宽高。后加的手工 ROI 保留。

原始来源、帧或定位发生变化时，旧向导不会继续提交到新来源。分析期间用户改变科学输入，旧结果不会被用于新图表。真实定量没有产生有效分组数据时，只保留 ROI 和条带面板，并提示检查质量原因；不会生成占位统计数据。

已有图稿不被删除。新的 WB 图组追加到已有面板下方，必要时扩大画布；整个布局仍可再次调整。条带面板宽度同时受原始裁切像素和工程最低 PPI（默认 300）约束，不通过提高输出 DPI 冒充原始分辨率。每个条带横条均为连续原图裁切，处在左右已纳入泳道之间的排除泳道像素依然保留，不进行静默拼接。ROI 只决定定量区域，不决定删除原图像素。

## 多曝光质量复核

在 WB 分析页点击“比较多曝光质量”。先核对实验、曝光比较系列、曝光 ID、配对 ID 和可选曝光秒数。同一曝光比较系列应包含相同实验中的全部可比样本和目标／内参。不同文件的目标与内参可以明确填写相同 `exposure_pair_id`；默认使用 `exposure_id`。

比较读取原始 ROI，计算边缘中位数背景、MAD 噪声估计、有符号净积分、内部信号的第 95 百分位、信噪比和原始削顶比例。无效像素、过小区域、缺身份、重复源像素、非正净信号、低信噪或原始削顶都会给出明确原因。

默认核验存储类型的上下限。如果仪器 ADC 是 12 位而 TIFF 存储为 16 位，应填写真实 `adc_bits=12`；也可填写黑电平和饱和上限。不同来源范围可通过 API 的 `source_ranges` 明确提供。浮点输入无法推测探测器范围时不作自动推荐。

推荐以 **完整实验／比较系列** 为单位，要求候选曝光覆盖同一组测量身份，逐个逻辑测量的 ROI 面积一致，并且目标／内参配对唯一。通过质控后，按本系列最弱条带的信噪优先排序，信噪超过 100 后不继续奖励更高亮度；同分时优先明确记录的较短曝光。

该评分是质量排序，不是仪器线性响应验证，也不是概率或准确率。曝光秒数不会用于自动缩放信号。没有完整且可用的候选时，界面明确报告无推荐。

点击“应用已勾选推荐”后，才更新逐 ROI 纳入状态和 control_roi_id，保留所有未选曝光与原件。使用逐 ROI 决策避免旧的 sample_id 级选择跨实验混淆。应用可以撤销／重做，之后需要重新运行定量；同一实验的不同曝光不会增加生物学 n。

## 实现与验证

- `web/modules/wb-domain.js`：候选行、原始矩形、身份校验、跨文件内参链接、连续裁切及图组布局。
- `web/modules/wb-workflow.js`：自动导入入口后的向导、精确编辑、真实定量与图表衔接、曝光复核界面。
- `workbench/wb_workflow.py`：原始 ROI 质量、完整曝光系列和解释性推荐，不写源图或自行提交纳入结果。
- `POST /api/wb/exposure-review`：当前项目与修订校验、原始平面读取、有界计算，返回只读推荐。
- `tests/test_wb_workflow.py`：削顶／弱信号／完整系列／跨实验／未知浮点范围／ADC／面积／重复源像素／纳入及真实定量联动。
- `tests/test_wb_workflow.mjs`：来源坐标、默认身份、未检出窗口、矩形编辑、跨文件配对、连续裁切、曝光应用。
- `tests/browser_wb_workflow.py`：通过实际浏览器上传合成 16 位 WB，生成 ROI 与图组，复核多曝光并保存／恢复工程。

测试使用明确标识的合成数据，用于数值和操作链验证。没有因此声称真实 WB 图像识别准确率、仪器定量线性或 Windows 真机性能已经经过独立验证。
