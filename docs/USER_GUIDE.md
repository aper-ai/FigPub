# Figure Workbench 使用手册

**将凝胶标注、原始数据定量和科研组图放在同一个本地工作台。**

版本：**0.6.1 · 完整科研工具包**。Windows 客户端、科学计算环境、Cellpose CPU 引擎及 cyto3 / nuclei 权重放在同一个下载包中。正式下载与验收状态以 [GitHub Releases](https://github.com/aper-ai/figure-workbench/releases) 中同版本的发行记录为准；开发分支不等于已经发布。本项目根据 GelFigure 与 ScieFig 的功能、工程格式和代码审计结果重新实现数据、计算、任务、渲染与交互层。当前不接入 FigScan。

本版统一项目操作、任务导航、分析设置和排版属性的视觉与术语；补充数据导入、保存失败恢复、项目重开、数值精度及导出尺寸的检查与修复。完整验收范围见 [0.6 验收清单](ACCEPTANCE_0.6.md)，数据流程修复见 [数据输入输出检查](QA_DATA_FLOW_0.6.md)。既有数值方法和科学口径见 [科学计算修复记录](QA_SCIENCE_0.5.md)。

当前发行见[本仓库 Releases](https://github.com/aper-ai/figure-workbench/releases)；迁移前完整版本历史见[原仓库发行记录](https://github.com/tuantuan007/figure-workbench/releases)。0.4 的 EXE 会启动外部浏览器；0.5 已改为独立窗口，但主程序与 Cellpose 分包。0.6 采用单个完整 Windows 包。仓库为私有，需要使用有访问权限的 GitHub 账号。

## 免安装浏览器组图版

独立组图入口是 **`Figure_Workbench_0.6.1_Browser.html`**，适用于只需要排版的场景，在现代桌面浏览器中打开，不需要启动 EXE、Python 或本地服务。代码、样式和字体内嵌在同一文件中，无运行时 CDN 依赖，图像和项目在浏览器本地处理。它是可本地打开的 HTML 文件；完整科研分析功能使用 Windows 完整包。

浏览器版提供批量图片导入、期刊预设、规则网格、大图组合、多选编组、对齐与等间距分布、编号、撤销重做、完整工程保存/重开，以及 PNG、内嵌字体 SVG 和带毫米尺寸的**栅格 PDF**。浏览器版专注组图；完整 WB/IHC/纤维/多通道分析继续在本机版使用。含无法正确显示的高级分析面板时，浏览器版明确拒绝打开并保留当前工程，避免静默损坏。

浏览器本地自动保存不能代替备份，建议及时下载 `.figwork`。浏览器清理站点数据或无痕模式会影响本地恢复。格式与互通边界见 [浏览器组图版说明](BROWSER_STUDIO.md)。

## Windows 独立客户端

完整解压 `Figure_Workbench_0.6.1_Windows_Full.zip` 后双击 `FigureWorkbench.exe`，直接打开独立的图研窗口。客户端使用 Windows 窗口和嵌入式 WebView2，计算服务在后台运行。文件选择和另存使用系统对话框；关闭窗口前提交当前输入并保存，关闭后停止它拥有的后台服务。重复启动会尝试恢复已有窗口。

包中附带专用 Python、固定科学依赖、隔离的 Cellpose CPU 环境与两种预训练权重。请保留 EXE 同级的 `runtime/`、`app/` 和 `cellpose/` 文件夹；不要只复制 EXE。Windows 10/11 还需要系统 WebView2 Runtime，或经过验收的固定运行时。未安装该系统组件时会提示安装；完整包不宣称在缺少 WebView2 的电脑上直接运行。

项目保存在 `%LOCALAPPDATA%\FigureWorkbench`，与程序目录分开。升级时保留该数据目录；建议先通过“另存项目”备份 `.figwork`。本版的 Cellpose 首次使用和推理均读取包内环境与权重，无需现场下载模型。运行状态区分“待检查、检查中、可用、不可用”；首次环境检查和模型加载可能需要等待，界面会显示任务状态。

Cellpose 用于细胞或细胞核实例分割，提供可继续人工拆分、合并、删除或补画的标签结果。它不参与 WB 条带识别、qPCR 计算或普通组图。内置 CPU 模型可在没有 NVIDIA 显卡的环境下运行；本版没有打包 CUDA/GPU 环境。模型适用性与分割质量仍需结合实际原图复核。

## 从源码运行

1. 安装 **Python 3.12 64 位**，完整保留本仓库文件。
2. Windows 双击 `start_windows.bat`；首次会创建 `.venv` 并安装固定依赖，需要联网。
3. Windows 默认启动独立客户端。已有依赖可执行 `python run.py`。
4. 首页选择 **WB 定量与出图、显微与组织图像、qPCR 数据分析、组图与排版**；也可打开合成示例或已有 `.figwork`。

普通编辑、分析、保存与导出在本机完成。Windows 关闭客户端窗口即可退出；源代码启动失败时保留诊断窗口查看错误。macOS/Linux 仍是本地服务与浏览器入口，可运行 `python3 launch.py`；本分支没有宣称这两个系统具备 Windows 原生客户端。

开发时可明确选择浏览器或仅运行后端，并使用独立工作目录：

```bash
python run.py --browser --data-dir ./my-workspace
python run.py --no-browser --data-dir ./my-workspace
```

Windows 源码环境应同时安装 `requirements.txt` 和 `requirements-desktop.txt`。不要把源码首次联网安装流程与已打包客户端的日常启动步骤混为一谈。

Windows 完整工具包构建使用经过 SHA-256 校验的 v0.4.0 基础运行时，其原始附件作为构建资料保存在 [build-runtime-0.4.0](https://github.com/aper-ai/figure-workbench/releases/tag/build-runtime-0.4.0)。该附件供构建流程使用，普通用户使用 0.6.1 完整包；来源及校验约定见[仓库来源说明](REPOSITORY_PROVENANCE.md)。

## 推荐操作顺序

首次启动先选择任务。每个入口显示当前所需文件和下一步；高级参数按需展开。标题栏“已自动保存”指本机当前工作区，“另存项目”生成带原件的 `.figwork`，“导出图稿”生成 PDF/PNG 等成品。新建、示例或打开另一项目前会确认切换，错误信息会留在界面中并提供重试。

完成分析后，点击分析标题旁的“查看结果”可定位到当前结果及 CSV、图表操作区。参数改变后的旧结果和未保存结果采用不同提示；后台计算或自动保存不会主动改变当前阅读位置。

### 凝胶与 WB

导入原始 TIFF/PNG，进入“凝胶与 WB”。可先裁切需要展示的区域，再识别泳道；核对检测线，修改样本名称。Marker 可以手动点击添加已知大小，或核对候选型号后确认。算法分数是匹配得分，不是正确率。

要自动定量出图，从首页选择 **“WB 定量与出图”** 并导入原图。向导整理候选条带行，生成原图坐标中的可编辑 ROI。确认目标蛋白/内参行、实验与样本身份、组别和生物学重复后，点击“生成定量 ROI 与图稿”：自动建立目标横条、内参横条和基于实际定量的统计图。跨文件内参先用内参图准备 ROI，再在目标图中明确选择对应内参配置。条带位置不能推断蛋白身份，阴性/缺失条带显示为需复核的参考窗口。

同一实验的多曝光不会成为额外生物学重复。“比较多曝光质量”以整套可比样本和目标/内参为单位检查削顶、背景、信噪和测量几何，再给出解释性推荐；只有点击应用才改变 ROI 纳入状态，可撤销。12 位 ADC 存入 16 位 TIFF 时填写真实 ADC 范围；探测器饱和上限应来自仪器参数。质控评分不等于验证仪器线性响应。

默认按真实身份配对内参，也可明确指定 control ROI。图片面板始终从原图连续裁切，保留中间被排除泳道的像素；版式大小同时受有效 PPI 限制。修改 ROI 或科学参数后旧结果会标记为需更新，应重新运行分析。完整操作见 [WB 工作流](WB_0.3.md)。

### qPCR

导入包含 `sample`、`target`、`ct`、`group`、`biological_replicate`、`technical_replicate` 的表格；界面可以下载字段模板。部分仪器表头和前导行也可识别，但组别必须来自数据或明确设置，不根据样本名称猜测。

TXT 必须是结构明确的逗号、Tab 或分号分隔表格，普通单列文本不会被猜成实验数据。支持 UTF-8、带 BOM 的 UTF-16 TXT 及 GB18030；旧式二进制 XLS 请先在原软件另存为 XLSX。TXT 导入、表格预览和 qPCR 使用同一分隔符判定，原文件字节及原数据行号保留。

在右侧选择原表的工作表，填写一个或多个内参基因与对照组；高级选项可设置组别映射、原表行号排除、Ct 上限和技术重复 SD 阈值，再运行。技术孔先聚合，在生物学样本层计算和汇总；查看逐孔质控和逐样本结果。检验在生物学重复 ΔCt 上进行，不拿技术孔或指数转换后的 fold 值扩大样本数。Welch/Student/配对 t 的同一实验与靶标对照比较采用 Holm 校正；ANOVA+Tukey 单独报告总体检验与已校正比较。配对依赖明确的 biological_replicate 身份，不按表格行号凑对。界面不自动添加显著性星号。生成的图表保留实际独立重复点及来源，可加入组图。

### 多通道显示与显微分析

多通道 TIFF 可以选择序列和帧；T/Z 的具体坐标同时显示。每个通道可改名称、伪彩、黑白点、Gamma 和显隐，支持合并、单独显示与分屏。多个同尺寸原图可组合为一个通道视图，各自保持原位深与来源；软件不会把某个通道转成另一个通道的 dtype。尺寸不一致时会明确拒绝，避免用隐式重采样冒充已配准图像。

每个显示配方最多 32 个通道；当前界面默认展示原系列的前 32 个，超过范围会提示，原文件仍完整保留。普通 RGB 的 Red/Green/Blue 是原文件颜色分量，不能据此推定为三种荧光染料；Alpha 默认不作为可见信号。显隐控制合并和分屏，单通道模式仍可查看已隐藏的那个通道。分屏与隐藏凝胶泳道不能同时使用，应拆成独立面板。

显示范围默认使用全幅有限原始值的最小/最大值，整数 RGB 使用自身完整数值范围；裁切不会重新拉伸对比度。也可以显式按百分位初始化：大图百分位采用有上限的确定性采样，界面保留采样标记和样本数，不能当成全像素精确百分位。百分位用于显示，原始测量不受影响。分析通道独立勾选，隐藏某个通道不等于把它从分析中删掉。分屏上的区域选择会映射回每块原图坐标；加入组图可拆为独立通道面板继续排版。

示例项目的第二份原件现在是三个真实存储通道的 16 位 OME-TIFF：合成核、合成胞质环和合成标记信号，名称均带 `SYNTHETIC`。核通道保留原示例的 9 个高斯目标，用于验证工作流；它不代表真实细胞图像的分割准确率。

选择原图和分析方法，明确分析通道与 ROI，填写阈值、背景、面积或线剖面参数；具有实际标定值时填写 μm/px。标定未知时只显示像素面积。分割轮廓叠加在原图上，便于检查漏检、粘连和伪目标。

把显微图加入组图后，可给图片面板设置比例尺的真实标定、长度和颜色。比例尺依据源像素与最终显示大小计算，不能从图像外观猜测。IHC 分析针对染色强度和阳性区域，不自动推断细胞 H-score。

Cellpose 在独立进程运行，主界面保持可操作；支持取消实际推理进程。只提供 CPU 的 cyto3 与 nuclei；缺少组件或官方权重校验不通过时会明确提示，不自动下载，也不以经典阈值结果代替模型结果。首次推理包含依赖与模型加载时间。

### 高级 IHC、纤维与人工复核

高级 IHC 使用自然 RGB 原图，支持 Macenko 染色估计、固定 H/DAB 向量、强度分级、阴阳例和伪影排除。GMM 不会把单峰数据强行拆成四级。锁定校准后，可在同批其他原图复用染色向量、白点和阈值；原图上的示例与排除坐标不随配方跨图搬移。0–300 指数按组织像素面积加权，明确标为 `pixel_weighted_score`，不是逐细胞 H-score。

纤维横截面和肌管分析接受结构通道、独立核通道及标记通道。支持经典分割、外部整数实例标签和内置通用 Cellpose；报告面积、最小 Feret、轴长/长宽比、骨架长度、中央/周边/不确定核、融合指数和标记分型。需要物理量时填写真实像素标定；本版未附带专用纤维/肌管训练权重。

分割结果下方可打开实例复核：选中两个种子拆分、选择多个实例合并、删除或补画，随后从原始图像重新计算全部相关指标。编辑配方与原始结果分别保存，支持撤销、重做、CSV、标签 TIFF 和工程重开。详见 [高级分析约定](HISTOLOGY_FIBERS_0.3.md) 与 [实例复核](INSTANCE_REVIEW_0.3.md)。

### 排版、保存与导出

在“组图排版”批量拖入文件，图片会一起加入并自动排版。右侧可以选择明确的列数与行数、横纵间距、边距，或采用左侧/上方大图模板。2×2 快捷项明确写为“2 列 × 2 行”；容量不足不会挤入或删除面板，而是提示调整。

Shift/Ctrl 点选或空白处框选多个面板；`Ctrl+A` 全选，`Ctrl+G` 编组，`Ctrl+Shift+G` 解组，`Ctrl+D` 复制。拖动整体移动，组的角点整体等比缩放。对齐/分布保持组内关系；自动重排前需明确解组。方向键移动 0.1 mm，`Shift` 加速，`Ctrl+Z / Ctrl+Y` 撤销/重做。

自动编号支持 A…Z、AA…，可改小写或数字。手工修改编号后自动锁定保留，清空表示隐藏。切换期刊预设可保留布局整体适配，或重新排版；字号保持物理大小，空间不足时原状态不变。Nature、eLife 和 Cell 条目的来源、适用范围及历史状态见 [期刊预设](JOURNAL_PRESETS.md)。

顶部“已自动保存”表示当前工作目录中的自动保存；“另存项目”下载包含原件、编辑配方和分析记录的 `.figwork` 文件。换电脑或切换新项目前，应保存这份可移动文件。自动保存维护当前工作区，长期归档应使用独立项目文件。

导出前运行检查并定位问题。输出 600 DPI 不会提高原图有效 PPI；应扩大源裁切、缩小最终放置尺寸或换用足够分辨率的原始来源。

| 格式 | 能保留什么 | 需要知道什么 |
|---|---|---|
| PDF | 物理尺寸、源 PDF 矢量对象、原生文字/线条、嵌入的应用字体 | 导入来源中已有的低清位图仍是位图；检查不会凭空增加细节 |
| SVG | 矢量图形、内嵌的图像与字体/字形 | SVG 不等于所有内容都是矢量；不支持的活动资源或复杂效果会明确拒绝而非静默丢弃 |
| PNG / TIFF | 按所设 DPI 渲染的最终图稿 | 成图是 RGB 显示结果；16 位原始实验数据保留在原件和工程中，不以成图代替原始定量输入 |
| PPTX | 原生应用文字、线条、矩形，分离的图像对象 | 每边 25.4–1422.4 mm；超限会明确拒绝，项目尺寸保持不变。导入 PDF/SVG 图表作为图片放入；字体以名称引用 |
| `.figwork` | 全部原件、来源关系、图稿布局、ROI、参数、分析记录和哈希清单 | 推荐的继续编辑与转移格式；打开时验证来源完整性 |
| 原始资料 ZIP | 与工程相同的完整来源资料和结构化状态 | 便于归档，不是实验真实性认证 |

PDF/SVG 可选择文字转轮廓以固定外观；转轮廓后的文字不再是可编辑文本。统计图的文字为稳定跨平台外观使用路径，原始数值和绘图配方仍可重新计算与生成。PPTX 若要求完全一致的字体外观，应在目标电脑安装附带许可的字体，或使用嵌入字体的 PDF。

## 性能与验证

`benchmarks/` 保存实际机器、合成输入、重复次数、逐次耗时与限制说明；`tests/` 包含数值、存储、迁移、几何、字体、任务和浏览器流程回归。具体结果见 [docs/VALIDATION.md](VALIDATION.md) 和 [docs/PERFORMANCE.md](PERFORMANCE.md)。

这些结果用于验证具体优化和回归，**不构成对原 GelFigure/ScieFig 整体速度或行业排名的比较**。没有真实多实验室数据集时，不声称定位/分割准确率领先。

## 版本边界

0.6 系列提供包含 CPU 模型的完整 Windows 包。0.6.1 修复分析重复提交、状态查询失败后的任务追踪、跨表返回任务、过期任务提示、按钮键盘语义和对话框焦点恢复，新增对应的真实浏览器异常流程验收；具体复现与边界见 [交互复核说明](QA_INTERACTION_0.6.1.md)。发布条件与证据清单见 [验收说明](ACCEPTANCE_0.6.md)，具体发行状态见上方 GitHub Releases；通过有限测试不能承诺任意输入都无缺陷，也不构成真实图像自动识别准确率或行业性能排名结论。

0.5.0 完成独立 Windows 窗口及既有科学工作流修复，历史验收范围见 [0.5 验收说明](ACCEPTANCE_0.5.md)。

0.4.0 补齐本轮组图需求，并保持既有科学分析功能。纯浏览器版的 PDF 是无损栅格成图，本机版 PDF 保留支持的矢量与文字；两者的分析能力和格式边界不同，不能将免安装组图入口宣传为全部分析都已搬进浏览器。

0.3.0 接续 0.2 的多通道与官方 Cellpose CPU 实现，补齐本次指定的高级 H/DAB、纤维/肌管测量、实例复核、多曝光推荐与 WB 自动 ROI/图稿流程。逐项说明见 [0.3 功能核对](FEATURE_AUDIT_0.3.md)。
本版设置了明确的资源上限：单份原件 128 MiB，便携工程的累计展开内容 512 MiB，单平面 6000 万像素，单 TIFF 系列按完整形状估算的解码大小 512 MiB。超出时会拒绝，不会静默缩图或把原始值转成 8 位。大图导出的时间与内存仍随裁切大小和面板数增加；有界缓存不等于任意工程都能保持固定工作内存。

完整 FCS 流式细胞术门控在本次审计的两个固定上游提交中均未发现实现；它不属于已确认存在而被省略的功能。ScieFig 的图像对象阈值分型也不能等同于流式门控。逐项证据见 [docs/UPSTREAM_FEATURE_STATUS.md](UPSTREAM_FEATURE_STATUS.md)，本次修复和剩余差异见 [docs/FEATURE_AUDIT_0.3.md](FEATURE_AUDIT_0.3.md)。

本版未附带上游专用纤维/肌管训练权重，尚未覆盖 H&E、油红 O 等全部染色专题、全部图表与风格模板、所有 CZI/ND2 专有格式或自动图像配准；不能将本版称为两套原项目全量等价替代。旧工程的复杂变换和不能确定对应原通道的合成强度记录，会保留历史状态并要求复核。标准多通道名称、伪彩、显示范围、显隐和分屏可恢复到新配置。当前没有 FigScan、FCS 门控、自动模型下载、GPU 推理、协同云编辑或已完成 Windows 签名验收的安装器。
