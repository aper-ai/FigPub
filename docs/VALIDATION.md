## 实际模型执行

[本轮 CPU smoke 记录](../benchmarks/cellpose_cpu_smoke.json) 使用 160×192 uint16 合成输入，包含 6 个构造高斯目标。nuclei 和 cyto3 均得到 6 个实例；前景面积分别为 2175 与 7689 px。总墙钟分别约 7.553 s 和 6.427 s，包含独立进程启动、依赖与权重加载及推理。

模型文件来自固定官方权重，nuclei 与 cyto3 的 SHA-256 均再次核验。运行使用 Cellpose 3.1.1.3、Torch 2.7.1+cpu、NumPy 2.0.2、CPU 2 线程、Numba workqueue；运行时不下载权重。原始图像逐值不变，所有输出质心位于原图范围。

这证明组件及模型计算链路可运行，不是实验图像的准确率评测，也不是 Windows 推理速度保证。

## 原图、工程和计算约定

API 回归验证：修订请求必须匹配项目 ID/revision/原始 mask hash；计算前后版本一致才返回有效结果。只读复核不写自动分割记录。保存配方、导出工程、创建新工程再打开后，操作可重放并恢复相同 mask SHA；原件下载仍逐字节一致。

IHC 数值测试包括两染色真值、单峰拒绝、四峰分级、白点及向量退化、阴阳例和排除区、跨图稳定锁定。纤维测试包括整数标签、像素方块凸包最小 Feret、各向异性物理标定、中央/周边/不确定/外部核及完整融合分母。实例拆分/合并检查前景并集守恒；补画/删除明确修改标签而不修改强度。

多曝光测试用原始 ADC/存储类型边界检查削顶，验证完整实验队列及目标/内参，而不为每个样本任意选择更亮曝光。应用推荐后再次定量，曝光数不增加生物学 n。
