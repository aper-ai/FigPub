# 图研 0.2：从多通道图到完整图稿

## 启动

将 Windows ZIP **全部解压**，双击 `FigureWorkbench.exe`。保留同目录的 `runtime/`、`app/`，以及完整包中的 `cellpose/`。浏览器会打开本机工作台；不需要安装 Python、pip 或 Node，也不需要联网下载模型。

启动窗口负责运行本机服务，请保持打开；退出时在该窗口按 `Ctrl+C`。关闭浏览器标签并不会停止服务。程序的 Windows 二进制及依赖已完成静态检查；本次尚无 Windows 真机启动、字体和 Office 动态验收记录。

## 先试一次完整流程

1. 点击“打开示例项目”。示例图像、通道和 Ct 表均明确标记为合成数据；如果已有项目，请先用顶部“保存工程”下载备份。
2. 在左侧选择名称含 `synthetic_nuclei` 的图像，再进入“通道与荧光”。示例是实际三通道 uint16 OME-TIFF；不是对同一灰度图重复着色。
3. 为各通道选择名称、颜色、黑点、白点及 Gamma；试用“合并”“单通道”“分屏”。分屏可以同时放入合并图，隐藏单个通道也会更新显示。
4. 切换“数据分析”，选择显微分析方法，**独立勾选要测量的原始通道**。在原图或分屏中的某个图块上框选 ROI，再运行。示例第一个原始通道用经典核分割会得到九个合成对象；这个数量是演示预期，不代表真实数据准确率。
5. 回到通道页，将通道图加入组图。每个独立面板可以继续调整位置、尺寸、标题和比例尺。在“组图排版”检查有效 PPI、字体及越界问题，再导出图稿。
6. 点击顶部“保存工程”，得到包含原件、通道配置、ROI、测量记录和排版的 `.figwork`。用“打开工程”可以继续编辑。

## 使用自己的数据

### 通道、系列和帧

导入 TIFF/OME-TIFF 后，先核对原始 series、帧及显示的 T/Z 坐标，再调整通道。对同一系列切换帧时，显示样式会保留；不同原始帧各自保留 ROI 与科学结果身份。更换系列时会按新的通道元数据初始化，避免错误沿用不对应的通道。

同尺寸的多个原始文件可以组合为一个显示视图，各自保留位深和来源。**尺寸相同不代表已经空间配准**；组合前应由使用者核实视野与空间对应。软件会拒绝尺寸不同的来源，不会在后台悄悄拉伸它们。

当前一个视图最多选择 32 个原始分量。普通 RGB 图片可自然显示；将 RGB 分量作为分析通道时需要明确选择，伪彩合成图不能替代真实 RGB 染色图进行 IHC 分析。

### 显示和分析

名称、伪彩、黑白点、Gamma、可见性控制显示。它们不会改写原件，也不会改变已经完成的原始值测量。分析页的通道、ROI、背景、阈值或来源改变后，原有结果会提示过期，应重新运行。

可用方法包括逐通道强度、手动/Otsu/Triangle/Li 阈值、线剖面、通道重叠与相关、经典核分割、基础 IHC，以及官方 Cellpose 的 CPU cyto3/nuclei 推理。手动阈值可以按通道分别填写，适合位深和信号范围不同的原件。原始强度不能直接和已做显示拉伸后的屏幕亮度互换。

矩形、椭圆、多边形 ROI 使用原图坐标；背景可选择不扣除、固定值或背景 ROI。线剖面需要画线并设置采样点数和线宽。知道真实标定时填写 μm/px，否则保持像素单位，不从图片外观推测物理尺寸。

### Cellpose

完整包包含官方 `cyto3` 与 `nuclei` 权重和独立 CPU 运行环境。选择 Cellpose 后可检查实际组件状态；首次运行包含依赖导入和模型初始化，分析在独立进程中执行，可取消。组件缺失、权重校验失败或推理出错会明确显示原因，不以阈值分割结果充当模型输出。

实例轮廓属于待复核候选，应对照原图检查漏检、粘连及伪目标。本版没有完整的实例拆分/合并/人工修订工作台，也没有 GPU 推理及全部组织、肌纤维、肌管专用流程。

### WB 和 qPCR

WB ROI 应填写样本、实验组、目标/内参角色及生物学重复身份。不同曝光和技术重复不能当成额外生物学重复。qPCR 的组别应来自原表或明确映射；排除原表孔后再核对逐孔质量提示。统计比较按独立生物学重复进行，技术孔先聚合，n=1 不会生成虚假的 SD 或 SEM。

## 保存与输出

- 顶部“已保存”表示当前工作区自动保存成功；“保存工程”才会下载可随身转移的完整 `.figwork`。
- PDF/SVG 用于最终排版与保留受支持的矢量内容；PNG/TIFF 是最终 RGB 图稿，不替代原始高位深实验数据。
- PPTX 保留应用产生的独立文字、线条、矩形和图像对象；导入的复杂 PDF/SVG 图表作为图片放置。
- Windows 当前数据位于 `%LOCALAPPDATA%\FigureWorkbench`；升级程序时保留该目录，并先下载工程备份。
