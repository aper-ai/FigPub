# 浏览器组图 · 0.6.2 候选版

浏览器组图是独立的科研图片排版入口。下载发行包内的
`Figure_Workbench_0.6.2_Browser.html`，用新版 Chrome 或 Edge 打开即可使用；不需要
启动 Python、Node、服务器或本机工作台。也可将同一文件部署在 HTTPS 静态网站，
通过链接打开。文件包含脚本、样式、拉丁字体和中文字体，不依赖 CDN。

这个入口专注组图。WB 定量、IHC、纤维分析、Cellpose、实例编辑和原始多通道分析
继续在完整本机工作台中使用。界面没有假分析按钮。

## 已实现的组图工作流

1. 批量选择、拖入或粘贴图片。每个文件成为一个面板，自动加入画布并按当前版式排列。
2. 选择期刊预设，或直接输入最终宽高，单位为 **mm**。
3. 选择规则网格、左侧大图＋右侧小图、上方大图＋下方小图；也可手工自由移动和缩放。
4. 通过原图裁切、标题、编号、文字、矩形和线条完成排版。
5. 检查原图实际 PPI、完整内容边界、重复编号、缺失字形和期刊提示。
6. 下载完整 `.figwork` 工程，以及 PNG、SVG 或明确标注为栅格页面的 PDF。

正式页面没有实验示例生成入口，默认打开为空白工作区。检测到本地自动保存时，必须主动选择恢复；文档中的 AI 演示图不内嵌到发行 HTML 中。

### 排版与编号

- 期刊预设、尺寸、版式、间距以及选中面板/标注的参数自动生效，不再提供单独的“应用”按钮。
  下拉选项即时提交；数字和文字在停止输入 350 ms 后更新，Tab、离开输入框或 Enter 可立即提交。
  中文输入法组字期间不提交，输入焦点、光标、宽高比锁定状态与裁切区展开状态会保留。
- 同一参数区域内的连续修改合并为一步撤销；连续调整画布宽高从本次编辑开始时的布局重新计算，
  避免叠加缩放。相同数值不新增历史记录，不清除可重做的操作。
- 空值、越界值、无效行列或无法容纳内容的布局不会修改已生效的图稿，输入框保留草稿并提示原因。
  可继续修正或按 Esc 恢复最近有效值。保存、导出前会提交有效草稿；存在无效草稿时先要求修正。
- 规则网格支持 2×2、3 列×2 行、2 列×3 行，以及自定义行列、边距和横纵间距。
- 行或列为 `0` 时，交给共享布局内核自动计算。明确指定的行列会被严格保留；
  如果容量不够，整个排版或导入操作会被拒绝，不会偷偷增加行数。
- 浏览器批量导入是一个原子操作：任一文件不支持、容量不足或布局失败，整批不加入，
  当前工作区保持原样。用户磁盘上的原文件不受影响。本机工作台还拥有独立素材库，
  可以保留已读入但尚未放入画布的素材，两种入口的这个交互有所不同。
- 网格和大图布局按裁切后的原图比例等比放入可用区域，不自动切掉图片内容。
  旋转包围盒、编号、标题和物理字号一起参与布局计算。
- 编号支持 `A…Z、AA…`、小写字母和数字；可以按视觉阅读顺序或素材加入顺序排列。
  关闭自动编号时，已手工锁定的编号仍保留。
- 手工编辑编号会锁定该编号，清空编号则设为不显示。自动排列、删图、加图时，
  锁定编号不会被覆盖，其他自动编号会避开它。可对所选面板恢复自动编号。

### 自由编辑、编组与历史

- 点击图片选择；Shift 点击追加或取消选择。拖动任一已选对象可一起移动。
- 图片右下角可缩放；单图默认等比，按住 Shift 可独立改变宽高。属性面板默认锁定宽高比。
- 多张图片或一个图片组被选中时，选区右下角提供整体等比缩放手柄。
  缩放保持图片之间的相对几何关系，编号和标题保留物理字号。
- 图片可以编组、解组、复制、置顶或置底。编组后再选择其中一张图，会选中整个组；
  撤销恢复的编组也按同一规则展开选择。
- 左齐、顶齐、水平居中、垂直居中、水平或垂直等距分布，均将每个图片组视为一个整体，
  不改变组内间距。对齐至少需要两个独立单元，等距分布至少需要三个。
- **编组范围是图片面板。** 文字、矩形和线条可以与图片一起多选、移动或对齐，
  目前不支持把标注纳入图片组，也不支持混合选区整体缩放。导入此类工程会明确拒绝。
- 图稿含有图片组时，自动排列、重新排版和新增图片后的自动排列会要求先解组。
  画布的“等比适配已有内容”和“只改变画布”可保留分组。
- 方向键移动 0.1 mm，Shift＋方向键移动 1 mm；吸附辅助对齐画布和其他面板。
- 一次完整拖动或缩放是一条历史记录。Esc、窗口失焦或指针取消会回滚未提交手势。
  `Ctrl/Cmd+Z` 撤销，`Ctrl/Cmd+Y` 或 `Ctrl/Cmd+Shift+Z` 重做。
- 保留最多 50 条配方历史；刷新后默认空白，主动恢复最新保存的工程后可继续编辑，不恢复整条撤销栈。

### 真实尺寸和期刊预设

本机版和浏览器版使用同一份 `web/modules/journal-presets.js`，并记录预设身份和来源快照。
预设说明、适用范围、历史状态和官方依据可在界面“规格说明与来源”中查看。

| 目录 | 尺寸含义 | 浏览器行为 |
|---|---|---|
| Nature 主刊主图 | 89 / 183 mm 栏宽，最高 170 mm | 应用宽度并提示范围；自动编号采用小写、8 pt；提示主图需要可编辑矢量 |
| eLife | 一般图最低 100 mm，预计整页宽图最低 200 mm | 明确标为上传宽度下限，不把它写成固定单栏/双栏 |
| Cell 2025 指南 | 历史指南中的最大宽度 85 / 114 / 174 mm | 明确标记历史来源；现行规范仍需投稿前复核 |
| Cell 自定义 | 当前官方数值未完整核验 | 保留用户画布，只记录期刊目标 |
| 通用 | 85 / 120 / 180 mm | 软件提供的便利尺寸，不宣称为期刊规范 |

预设不会自动修改源图片内部已有的文字或图表。手工锁定编号也不会被强制改写。
期刊要求的具体适用范围、官方来源和已核验字段见 [JOURNAL_PRESETS.md](JOURNAL_PRESETS.md)。

画布调整有三种模式：等比适配全部现有内容、按照当前版式重新排列、只改变画布。
预设的自动编号样式与字号先应用，再计算适配，避免字号增大后越界。
期刊的编号与字号默认值只在选择预设时设置；随后修改尺寸不会覆盖用户调整的编号样式或字号。
调整方式作为工程设置保存，单独改变该选项不会再次缩放现有内容。

## 文件格式与真实性边界

### 输入

支持静态 PNG、JPEG、WebP 和安全 SVG。SVG 可以包含内部渐变、裁切、路径、静态文字、
内嵌 PNG/JPEG/WebP、经过同样检查的嵌套 SVG，以及内嵌字体。外部资源、脚本、事件处理器、
动画、外部实体、活动嵌入和过深嵌套会被拒绝；不会悄悄删除这些内容后继续导入。

TIFF、PDF、多页文件、动态 PNG/WebP 和原始多通道图像请在本机版打开。
带非默认 EXIF 方向的照片会明确要求先另存为方向已校正的 PNG，保证浏览器与本机工程的
原图坐标一致，不会一边旋转显示、一边按另一方向保存裁切坐标。

PNG 16 位原件可以用于组图，并完整保存在工程中；浏览器 PNG/PDF 导出是 8 位显示结果，
不会伪称为 16 位原始数据或用于定量的数值输出。图稿检查会对此提示。

### 输出

| 格式 | 实际内容 | 注意事项 |
|---|---|---|
| `.figwork` | 项目 JSON、全部已导入原件、SHA-256 清单，原件字节不改变 | 与本机工作台的 ZIP 工程格式互通；是长期保留原件和可编辑配方的首选 |
| PNG | 150 / 300 / 600 DPI 的 8 位合成图，带 `pHYs` 分辨率元数据 | 无损编码；提高输出 DPI 不能提高低分辨率原图的细节 |
| SVG | 毫米画布、图片布局、矢量标注、可编辑文字、内嵌原件与所需字体 | 图片仍是图片；源 SVG 以内嵌对象保留，不拆成可独立编辑的内部曲线 |
| PDF | 真实毫米页面，150 / 300 / 600 DPI 合成 RGB 图，以 Flate 无损压缩嵌入一页 PDF | **这是栅格 PDF，不保留可编辑文字或曲线。** Nature 等要求可编辑矢量时，应选 SVG 或本机版矢量 PDF |

主图文字使用随包携带的 DejaVu Sans 和 Noto Sans CJK。构建时从实际字体读取字形覆盖，
导出前检查字符；遇到缺失字形或无法由同一字体覆盖的混合文本会拒绝导出并说明原因，
不会默默输出方框。编号、标题和文字标注支持多行，行距与本机版采用同一 1.25 em 规则。

源 SVG 自身的文字、字体、内部位图仍需要核验；这与工作台新加的标号/标题字体是两层内容。
导入含源 SVG 文字或位图时会提供提示。SVG 合成文件并不代表每一个源对象都满足期刊的
内部可编辑性要求。

### 打开已有工程

浏览器可以打开本机导出的、原件和呈现能力均在支持范围内的 `.figwork`，支持 ZIP 的
stored 和 deflate 方法，并校验项目及每份原件的 SHA-256、大小、路径和清单完整性。
基本图片、裁切、翻转、旋转、编号、标题、标注、比例尺、图片组及未知扩展字段可保存往返。

如果面板需要浏览器入口尚未实现的通道视图、强度变换、凝胶专用标注、多帧选择等，
会明确要求回到本机工作台，**整个工程不会替换当前工作区**。没有被渲染的科学内容不会被
静默丢掉。可支持工程中的既有科学结果保持为只读记录，浏览器不重新计算它们。

## 保存、资源上限与性能

- 图片通过浏览器 File API 读取，只在当前浏览器内处理。单文件发行版的 CSP 禁止网络连接；
  查看官方依据链接是用户主动打开的新页面，不是上传项目。
- “清除本地数据”在同一事务内清除工作区与原件，失败时回滚并明确提示；保留的代际记录不包含素材。另一个窗口持有的旧工程不能在清理后自动写回。
- IndexedDB 自动保存原件与最新提交的配方。写入失败或浏览器不允许本地数据库时，
  状态栏和提示会明确要求下载工程；仍可编辑并手动下载 `.figwork`。
- IndexedDB 不等于云备份，清理站点数据、隐私模式结束、更换浏览器或移动到不同文件地址，
  都可能使原工作区不可用。请定期下载工程。
- 自动保存只捕获已经提交的配方。手势中的临时几何不会落盘，取消手势不会覆盖已保存位置。
- 原件按 SHA-256 去重；重复放入同一原件只增加面板，不重复保存一份原件。
- 撤销历史深拷贝可编辑配方，科学结果、审计记录、素材元数据和未知只读扩展共享引用；
  拖动和撤销不会把大结果复制 50 份。实际写入 IndexedDB 或工程文件时才序列化完整数据。
- 拖动/缩放按动画帧合并绘制，松开时补最后一帧；属性、完整检查和保存不在每个 pointermove 中运行。
- 单份原件上限 64 MiB，累计工程数据 192 MiB，原件最多 256 份，面板最多 500 个，
  标注最多 1000 个，工程 JSON 最多 8 MiB。
- 单张源图或 SVG 内嵌位图合计最多 4000 万像素；SVG 文本最多 48 MiB、5 万个元素、
  三层嵌套。复杂 SVG 可能比普通图片更耗时。
- 栅格成图最多 4000 万像素，单边不超过 16384 px。超过时会提示降低 DPI 或画布尺寸。
  原图 PPI 按原始裁切像素与最终物理尺寸独立计算。

这些是明确的资源约束和实现策略，不构成“比所有同类工具快”的性能结论。

## 开发、构建和验证

普通使用者只需要发行的 HTML。以下命令面向开发者。

```bash
npm ci
node scripts/build_browser_studio.mjs
```

默认产物：`dist/Figure_Workbench_0.6.2_Browser.html`。可把输出路径作为第一个参数。
构建使用锁定的 esbuild 0.28.2；脚本、样式、字体、字体覆盖和许可证一起内嵌。
文件约 17 MiB，主要为完整中文字体。运行时不需要 esbuild 或 Node。

源代码按归档、输入安全检查、项目配方/分组、渲染、二进制导出、本地保存分成模块。
布局与编号直接复用 `web/modules/layout-engine.js`；期刊目录直接复用共享模块。

可运行的自动检查：

```bash
node --test tests/test_browser_studio.mjs
python -m pytest -q tests/test_browser_studio_archive.py
```

上述检查覆盖归档安全与原件字节、浏览器/本机实际工程互通、Pillow 识别 PNG DPI、
PyMuPDF 读取和渲染真实 PDF、抽取像素无损一致、实际字体 cmap、分组单元、整体缩放、
配方隔离、只读大结果共享，以及 SVG 内嵌资源和多行文本。

真正的浏览器工作流另有独立脚本：

```bash
BROWSER_EXECUTABLE=/path/to/chromium python tests/test_browser_studio_ui.py
```

它打开构建后的 `file://` 单文件，阻断并记录 HTTP/HTTPS 请求，执行导入、拖放、编号到 AA、
版式、分组手势、撤销、期刊适配、安全 SVG、PNG/SVG/PDF 下载、IndexedDB 恢复、完整工程
往返和失败回退；只有全部完成才写入 `passed: true`，浏览器不能启动不会被标为通过。

**当前交付环境的真实 UI 验收尚未完成。** 容器策略阻止 Chromium 进程所需的套接字；
受支持的云浏览器又不允许打开本地 `file://`，并无法访问容器的 localhost。
因此这里已运行的是上述非 UI 检查与构建，没有声称完成截图或端到端浏览器验收。
发布前应在正常桌面或 CI 浏览器环境运行独立脚本。
