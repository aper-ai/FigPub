# 0.6 完整工具包验收

## 交付范围

默认交付为 `Figure_Workbench_0.6.1_Windows_Full.zip`：Windows 独立客户端、科学计算环境、隔离的 Cellpose CPU 环境和 cyto3 / nuclei 官方权重放在同一目录中。用户完整解压后运行 `FigureWorkbench.exe`。源码 ZIP 与独立组图 HTML 为另外两个可选交付物。

完整包仍使用 Windows WebView2 Runtime。模型采用 Cellpose 3.1.1.3 与 PyTorch 2.7.1 CPU，不包含 CUDA；使用包内权重，无运行时模型下载。图像处理、计算、保存及导出均在本机完成。

## 必须通过的验收

| 层次 | 直接检查的内容 | 不接受的替代证据 |
|---|---|---|
| 数值与后端 | 原始位深、ROI、WB 配对/重复口径、多曝光、qPCR、IHC、纤维、实例编辑、统计、保存、迁移、导出 | 仅显示一个成功提示或仅测试接口状态码 |
| 前端逻辑 | 状态与来源隔离、输入提交、异步重绘、撤销重做、排版、组图保存、错误恢复；oxlint | 仅编译通过 |
| 完整浏览器工作流 | 真实控件导入、设置参数、分析、修改、结果 CSV、项目往返和图稿下载；全部既有流程加新增专业界面流程 | 模拟点击处理函数或直接写入成功状态 |
| 专业界面 | 1024×768、1280×800、1440×900 首页、分析与排版截图；关键操作可达；中文长文件名；合理字段宽度；排版显示与精度分离 | 仅检查 CSS 字符串 |
| 包内 Cellpose | 最终 ZIP 解压出的独立解释器、运行时和两份已校验权重均实际执行推理 | 开发环境模型成功或仅核对文件名 |
| Windows 原生客户端 | 实际 EXE 启动独立窗口，系统文件选择和另存、导入、科学计算、下载内容、保存失败、关闭与后台清理、重开 | 在浏览器打开同一网页 |
| 发布来源 | 源码提交、工作树摘要、完整 ZIP、内部清单、解压收据、测试报告及交付附件逐项绑定 | 旧提交测试报告、重新构建的未测附件 |

浏览器矩阵由 `scripts/run_acceptance.py` 列出的所有套件组成，任意失败会保留错误、截图和执行日志。原生与包内推理验收直接使用最终 `Windows_Full.zip` 解压到全新中文、空格目录的文件，不在测试时临时组合主程序和组件。

## 本轮针对的数据问题

新增故障注入和往返检查覆盖：项目新建/打开时写盘失败，原件注册表写盘失败后的重试，分析记录超过项目大小限额，表头以外的非空数据，qPCR Excel 布尔 Ct 和超大无关工作表，物理尺寸与目标格式限制，以及简洁数值显示不应改变实际存储值。具体故障、修复和回归见 [数据输入输出检查](QA_DATA_FLOW_0.6.md)。

新增真实界面测试使用明确标记的合成数据：中文样本与组名、UTF-16 TXT、三份独立生物学重复及高精度 Ct。结果与独立计算的 `2 ** (20 - 18.123456789)` 比较，并检查 CSV 中每个样本的身份和完整精度。生成图表后编辑面板物理宽度，验证未编辑的输入聚焦/离焦和自动保存不会取整原值，显式编辑仍正确提交。随后保存、重开 `.figwork`，核对原件字节和哈希、几何、分析记录与 PDF 物理页面尺寸。

结果导航同时验证鼠标和键盘激活：点击前直接测量入口是否在中央可视区域内，点击后直接测量 CSV 与图表操作是否进入视野，再进行下载操作，避免测试工具自动滚动掩盖布局问题。导航不得重新计算或修改项目；后台完成通知和保存重绘不得自动滚动或抢走原有焦点。

画布适配在三种窗口尺寸下分别通过真实的放大和“适合窗口”控件验证，直接比较 SVG 显示边界与容器扣除内边距后的可用区域，要求完整可见、无滚动溢出，同时保持项目的毫米几何不变。字体或窗口更新可能替换 DOM 节点，验收脚本仅对瞬时失效的滚动节点重新定位；超时、不可见和边界错误仍判定失败。

## 发布门槛

`scripts/release_gate.py` 要求所有 Python、Node、浏览器、原生与包内模型证据均存在并成功，测试数不得为零，失败/错误/跳过不得被忽略。源码必须干净且未在测试中改变。完整 ZIP 的内部清单覆盖主程序、科学依赖和 Cellpose 文件；解压目录中的文件在验收前后核对完整性。

验收工作流只生成候选文件。`release/validated-0.6.1` 触发的发行工作流只接受同一提交已通过的候选产物，重新校验后上传原字节；不会在发布阶段重新构建软件。正式发行附件为：

1. `Figure_Workbench_0.6.1_Windows_Full.zip`
2. `Figure_Workbench_0.6.1_Source.zip`
3. `Figure_Workbench_0.6.1_Browser.html`
4. `Figure_Workbench_0.6.1_QA_Evidence.zip`
5. `RELEASE_ACCEPTANCE.json`
6. `SHA256SUMS`

准确提交、每类实际通过数量、运行环境、包大小和 SHA-256 以对应发行的收据与原始报告为准。开发中的清单描述验收要求，不构成提前通过的声明。

## 结论边界

这些检查验证已覆盖的数值例、异常恢复与实际操作路径，不能证明任意实验图像都能正确分割或任意仪器导出格式都可识别。自动条带候选、细胞标签、IHC 分级与曝光推荐仍需使用者依据原图、样本身份和实验条件复核。合成数据测试不用于声称真实实验准确率或行业性能排名。
